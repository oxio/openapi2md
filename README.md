# openapi2md

CLI tool for converting OpenAPI 3.0 and 3.1 JSON/YAML specifications into clean, deterministic GitHub-flavored Markdown documentation.

## Installation

### Quick Install (Recommended)

One-liner that auto-detects your OS and architecture:

#### Using curl

Latest version:

```bash
curl -sL https://raw.githubusercontent.com/oxio/openapi2md/main/install.sh | bash
```

Specific version:

```bash
curl -sL https://raw.githubusercontent.com/oxio/openapi2md/main/install.sh | bash -s -- v1.0.1
```

#### Using wget

Latest version:

```bash
wget -qO- https://raw.githubusercontent.com/oxio/openapi2md/main/install.sh | bash
```

Specific version:

```bash
wget -qO- https://raw.githubusercontent.com/oxio/openapi2md/main/install.sh | bash -s -- v1.0.1
```

### Go Install

If you have Go installed:

Latest version:

```bash
go install github.com/oxio/openapi2md@latest
```

Specific version:

```bash
go install github.com/oxio/openapi2md@v1.0.1
```

### Manual Download

Download the appropriate binary for your platform from the [latest release](https://github.com/oxio/openapi2md/releases/latest) (or a specific tag on [GitHub Releases](https://github.com/oxio/openapi2md/releases)).

#### Linux

```bash
# amd64 (x86_64)
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-linux-amd64 -o openapi2md && chmod +x openapi2md && sudo mv openapi2md /usr/local/bin/

# arm64 (aarch64)
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-linux-arm64 -o openapi2md && chmod +x openapi2md && sudo mv openapi2md /usr/local/bin/

# arm (32-bit, armv7)
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-linux-arm -o openapi2md && chmod +x openapi2md && sudo mv openapi2md /usr/local/bin/
```

#### macOS

```bash
# Apple Silicon (M1/M2/M3/M4/M5)
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-darwin-arm64 -o openapi2md && chmod +x openapi2md && sudo mv openapi2md /usr/local/bin/

# Intel (x86_64)
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-darwin-amd64 -o openapi2md && chmod +x openapi2md && sudo mv openapi2md /usr/local/bin/
```

#### Windows

```powershell
# amd64 (x86_64)
Invoke-WebRequest -Uri "https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-windows-amd64.exe" -OutFile "openapi2md.exe"

# arm64
Invoke-WebRequest -Uri "https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-windows-arm64.exe" -OutFile "openapi2md.exe"
```

Or using PowerShell with `curl` alias:

```powershell
curl -sL https://github.com/oxio/openapi2md/releases/latest/download/openapi2md-windows-amd64.exe -o openapi2md.exe
```

```bash
go build -o openapi2md .
```

## Usage

Convert a JSON or YAML OpenAPI specification to Markdown (written to stdout by default):

```sh
openapi2md openapi.yaml
openapi2md openapi.json -o docs/API.md
```

Read from standard input:

```sh
cat openapi.yaml | openapi2md --toc -o docs/API.md
openapi2md - < openapi.json
```

Validate an OpenAPI specification without generating output:

```sh
openapi2md validate openapi.yaml
```

### Flags

| Flag | Description |
| --- | --- |
| `-o, --output <path>` | Output Markdown file path (defaults to stdout) |
| `--title <title>` | Override the document title from `info.title` |
| `--spec-url <url>` | Optional OpenAPI spec URL/path to mention in the header (e.g. `/openapi.json`) |
| `--header <comment>` | Custom header comment at the top of the output (default: `<!-- Code generated by openapi2md; DO NOT EDIT. -->`) |
| `--no-header` | Omit the generated-file header comment |
| `--toc` | Include a Table of Contents |
| `--no-schemas` | Omit the Schemas section |

### Subcommands

- `openapi2md validate [input]` — Parse and validate an OpenAPI JSON/YAML document.
- `openapi2md version` — Print the tool version.

## Supported OpenAPI Features

- **OpenAPI 3.0 & 3.1** in both **JSON** and **YAML** (including numeric status keys and YAML anchors/merge keys)
- **Schema composition & JSON Schema 2020-12**: `oneOf`, `anyOf`, `allOf`, `not`, `discriminator` (with mapping), empty/untyped `any` schemas, boolean schemas (`true` / `false` -> `any` / `never`), `const`, `enum`, `prefixItems` tuples, `additionalProperties` maps, OpenAPI 3.0 `nullable`, and OpenAPI 3.1 type arrays (`["string", "null"]`, `["string", "integer"]`)
- **Full local `$ref` resolution** for schemas, parameters, request bodies, responses, headers, examples, security schemes, callbacks, and path items (with cycle protection)
- **Complete API documentation**: info metadata, servers & server variables, authentication/security schemes, tag-grouped endpoints with deterministic sorting, path-level parameter merging, response headers, webhooks, callbacks, deprecation notices, and validation constraints
- **Collision-free GitHub Markdown anchors**: every internal `#anchor` link is guaranteed to point to a unique heading
